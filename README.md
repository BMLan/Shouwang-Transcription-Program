# 兽王录入计划
## 计划简介
《兽王》是作家雨魔（原名张凯）创作的奇幻小说。目前，网络上关于《兽王》的电子资源较为零散且良莠不齐。本计划旨在将全套《兽王》整理为经过校对的、可编辑的电子文件。

特别说明：本计划涉及的全部内容，仅供个人学习、研究或欣赏使用。
