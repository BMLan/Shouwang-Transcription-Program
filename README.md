# 兽王录入计划
> 我抱着小犬狼作为精神支柱，闯过了儿时的无数创伤——谨以此项目纪念我已逝的童年。
## 项目简介
《兽王》是作家雨魔（原名张凯）创作的奇幻小说。目前，网络上关于《兽王》的电子资源较为零散且良莠不齐。本项目旨在将全套《兽王》整理为经过校对的、可编辑的文本文件。

特别说明：本项目涉及的全部内容，仅供学习、研究和欣赏使用。如有侵权，请与项目发起人联系。

因本人水平有限，录入过程中难免会出现疏漏。若发现任何文本错误，或有任何意见及建议，欢迎与本人联系。

同时，也欢迎各位《兽王》爱好者通过邮件与本人谈天说地。

项目发起人的联系方式：ytzhang0587@foxmail.com

1. 将兽王01-26的**正文**整理为格式规范、经过校对的文本文件。
2. 将兽王27-29的**正文**整理为格式规范、经过校对、可编辑的文本文件。
